# Decisiones arquitectónicas

## 1. Pedagogía antes que automatización
La plataforma no se concibe como un generador de código sino como un sistema para comprender y evaluar lo que se escribe.

## 2. Veredicto basado en evidencia
La IA no sustituye la ejecución ni las pruebas; explica el resultado y marca su origen.

## 3. Documentación modular
La arquitectura del repositorio se organiza para que un agente encuentre el módulo correcto sin leer todo el proyecto.

## 4. Compatibilidad sobre reescritura total
Se conservan los documentos históricos y se añade la navegación central sin romper la base actual del proyecto.
