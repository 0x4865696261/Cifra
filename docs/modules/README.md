# Índice de módulos de Cifra

Este directorio agrupa la documentación funcional del proyecto. Su objetivo es que un agente o desarrollador localice el módulo correcto sin leer todo el repositorio.

## Módulos principales
- [Estudio](./estudio/README.md)
- [Retos](./retos/README.md)
- [Incidentes](./incidentes/README.md)
- [Biblioteca](./biblioteca/README.md)
- [Matemáticas](./matematicas/README.md)
- [Lenguajes](./lenguajes/README.md)

## Otros subsistemas relevantes
- IA y prompts: `src/lib/ai`
- Ejecución: `src/lib/ejecucion`
- Módulos y registro: `src/lib/modulos`
- Datos y persistencia: `src/lib/app-data`, `src/lib/db.ts`
- Autenticación: `src/lib/auth`

## Regla de navegación
Si la tarea afecta a una funcionalidad concreta, leer primero:
1. este índice general,
2. el módulo afectado,
3. la documentación del área concreta,
4. el código del archivo relevante.

No se recomienda abrir más documentación que la necesaria para la tarea.
