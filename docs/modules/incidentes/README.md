# Incidentes

## Responsabilidad
El módulo de incidentes enseña a analizar fallos reales simulados, relacionar causas con síntomas y comparar una explicación con una guía honesta basada en evidencia.

## Archivos principales
- `src/routes/incidentes.*`
- `src/lib/incidentes/`
- `src/lib/ai/incidentes*`

## Relación con otros módulos
- Usa la misma lógica de análisis del estudio y del reto.
- Salva la diferencia entre análisis de fallo y resolución de reto.
- Se conecta con la ejecución y con la IA estructurada.

## Estado
- El flujo base está implementado y se apoya en pruebas y evaluación local.
- La revisión principal está en la claridad del diagnóstico y la trazabilidad de la conclusión.
