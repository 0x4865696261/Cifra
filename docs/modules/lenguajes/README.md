# Lenguajes

## Responsabilidad
El módulo de lenguajes compara cómo resuelve el mismo problema distintos lenguajes y ayuda a entender las diferencias que cambian la forma de escribir, leer y validar software.

## Archivos principales
- `src/routes/lenguajes.tsx`
- `src/lib/modulos/lenguajes`
- `src/lib/content/`

## Relación con otros módulos
- Sostiene la comprensión del estudio y la biblioteca.
- Se apoya en la idea de que el mismo problema admite distintas expresiones y restricciones.

## Estado
- Funcional como módulo de comparación pedagógica.
- La evolución principal es controlar la profundidad de la comparación sin perder claridad.
