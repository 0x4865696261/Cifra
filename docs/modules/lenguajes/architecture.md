# Lenguajes — arquitectura

El módulo compara soluciones en diferentes lenguajes con una lógica de contraste pedagógico: 
- mismo problema;
- distintas expresiones;
- comportamiento y restricciones distintas;
- decisiones que cambian la forma de razonar.

No es solo una lista de ejemplos; es un mecanismo para entender la relación entre sintaxis, semántica y diseño.
