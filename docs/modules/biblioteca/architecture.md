# Biblioteca — arquitectura

La biblioteca está pensada como una red de conocimiento que conecta conceptos, no como un repositorio de definiciones aisladas.

Cada hilo debe responder a preguntas del tipo:
- qué es esto;
- por qué importa;
- qué lo sostiene;
- cómo se relaciona con otros conceptos;
- qué herramientas o pruebas lo validan.

Esto permite que el aprendizaje tome forma de sistema y no de listado lineal.
