# Biblioteca

## Responsabilidad
La biblioteca organiza conceptos clave del aprendizaje técnico en formato conectado: no es una lista suelta, sino un mapa de ideas que relaciona fundamentos, lenguaje, depuración, memoria, complejidad y arquitectura.

## Archivos principales
- `src/routes/biblioteca.*`
- `src/lib/content/`

## Relación con otros módulos
- Expande y enlaza conceptos introducidos por estudio, retos, lenguajes y matemáticas.
- Funciona como capa de referencia y navegación conceptual.

## Estado
- Consolidada como sistema de navegación conceptual clave del producto.
- La prioridad de evolución es mejorar la granularidad, contextualización y trazabilidad de cada hilo de conocimiento.
